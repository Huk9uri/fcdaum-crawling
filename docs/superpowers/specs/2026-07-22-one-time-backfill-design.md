# FC다움 일회성 시작일 백필 설계

## 목적

2026년 1월 1일 00:00 KST부터 현재 실행 시각까지 데이터를 한 번 일괄 수집하고, 이후 옵션 없는 정기 실행은 기존처럼 최근 1개월을 수집한다.

## 실행 방식

```powershell
python crawling.py --from-date 2026-01-01
```

- `--from-date`가 있으면 해당 날짜 00:00 KST를 수집 시작 시각으로 사용한다.
- 시작 날짜와 정확히 같은 데이터도 포함한다.
- `--from-date`가 없으면 실행 시각 기준 1개월 전을 시작 시각으로 사용한다.
- 환경변수와 기본 설정은 변경하지 않으므로 일회성 실행 후 별도 원복이 필요 없다.

## 적용 데이터

- 리포트: `visitDate >= 시작 시각`
- 품질미션: `regDate >= 시작 시각`
- 리포트 문제항목: 수집 대상 리포트별 과태료·영업정지 필터 전체 페이지

## 검증

- 날짜 문자열을 KST 자정으로 변환하는지 검증한다.
- 날짜 옵션이 있을 때 명시 시작일을 사용하고 없을 때 최근 1개월을 유지하는지 검증한다.
- 잘못된 날짜 형식과 미래 시작일을 거부하는지 검증한다.
- 실제 백필 후 DB 적재 결과와 재실행 기본 동작을 확인한다.
